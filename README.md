## 🔄 Metodología Ágil (Scrum)
El desarrollo del prototipo se organizó bajo **Scrum** en tres Sprints de 2 semanas:
* **Sprint 1 (Arquitectura Base y Autenticación):** Estructura del repositorio en GitHub, entorno web y módulo de registro, inicio de sesión y gestión de roles (`HU-01`).
* **Sprint 2 (Gestión de Recursos y Catálogo Interactivo):** Interfaz principal, formulario de publicación de materiales académicos y motor de búsqueda con filtros (`HU-02`, `HU-03`).
* **Sprint 3 (Pasarela Conceptual, Reputación y Validación Integral):** Carrito de compras con pasarela de pago simulada, sistema de calificaciones y reseñas, y panel de administración (`HU-04`, `HU-05`, `HU-06`).
